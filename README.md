# make-knowledge-cards

把一个 Agent 变成"知识卡片工厂"：给它一篇文章，它给出 5-8 张能背、能复习的卡片。

纯提示词型 Agent Skill，无脚本、无外部依赖、不联网。

## 1. 项目解决什么问题

长文读完记不住重点，手动摘抄又太慢；直接让 AI"总结一下"，通常得到一份什么都留一点的摘要——信息密度低，既背不下来，也没法复习。

这个 Skill 不做摘要，做取舍：以"删掉这张卡，读者会不会丢掉原文的重要信息"为唯一判据，把文章压到 5-8 个知识点，一条一张卡，并强制每张卡配一个解释和一个例子或自测题，让卡片可以脱离原文独立使用。

## 2. 主要功能

- **两种输入**：粘贴正文；本地 `.md` / `.txt` 文件路径。
- **固定卡片结构**：每张卡四项齐全——标题（≤16 字）、核心知识（一句话，≤50 字）、简明解释（2-4 句）、例子或自测问题。
- **选点规则**：优先保留核心主张、机制和因果、关键定义、方法与步骤、关键数据与边界、常见易错点；背景铺垫、行业套话、过渡句、修辞、重复强调一律舍弃。
- **去重合并**：同一知识点的多处表述合并；同一动作在不同日期重复出现合并；结论与其直接机制合并。
- **不编造**：只用原文有的信息，解释里不补充原文没有的因果、机制和"常识"；关键信息缺失时，在卡片末尾单独一行标"原文未说明：……"。
- **数量自适应**：正常文章 5-8 张；信息量确实不足时给 2-4 张，并在开头注明"原文信息量有限，共 N 张"，不为凑数拆空洞卡片。
- **按文本类型调整**：教程按阶段与判断条件成卡，数据报告先给结论再把数字下沉，观点评论取主张与反驳，清单逐条成卡，短文本不靠常识扩写。
- **语言跟随**：卡片语言跟着提问语言走；英文原文未指定语言时输出中文，专有名词保留英文原词。
- **可留存**：默认在对话中输出 Markdown；要求保存时写成 `<主题>-知识卡片.md`。

## 3. 安装方法

**前置条件：无。** 不需要 Node、Python、API key 或任何第三方服务。

1. 把 `skills/make-knowledge-cards/` 整个目录复制到你所使用 Agent 的 skills 目录。常见位置：
   - Codex：`~/.codex/skills/`
   - Claude Code：项目内 `.claude/skills/` 或 `~/.claude/skills/`
   - 其他遵循 Agent Skills 规范的产品：其对应的 skills 目录
2. 重新加载 Skill 列表（重启应用或执行 reload）。
3. 确认目录里存在 `SKILL.md`，且 frontmatter 的 `name` 与目录名一致（`make-knowledge-cards`）。

Windows PowerShell 复制示例：

```powershell
Copy-Item -Recurse -Force ".\skills\make-knowledge-cards" "$HOME\.codex\skills\"
```

`agents/openai.yaml` 只提供界面展示用的 `display_name`、`short_description`、`default_prompt`，删掉它不影响 Skill 运行。

结构校验（可选）：用 skill-creator 附带的 `quick_validate.py` 检查 frontmatter 与命名。该脚本不属于本项目，需要你另行准备。

## 4. 使用方法

放进 skills 目录后，直接用自然语言提需求即可。常见触发词：知识卡片、学习卡片、复习卡片、把文章整理成卡片、提炼知识点做成卡片。

**粘贴正文**

```text
把这篇文章做成知识卡片：<粘贴全文>
```

**给文件路径**

```text
帮我给 ./notes/光合作用.md 做知识卡片
```

**追加要求**（会改变选点和数量，不改变卡片结构）

```text
只保留概念和机制，别写操作步骤，最多 6 张，保存到 ./notes/cards.md
```

**多篇文章**：一次给多篇时，会逐篇处理、每篇一组卡片并标注出处，不混成一组。

## 5. 输入输出示例

### 示例一：粘贴英文文章 → 中文卡片

输入（节选，原文为英文的四六级备考文章）：

> The total score is 710, and the passing line is 425... Listening and reading together make up 70 percent of the total grade... Writing and translation, each worth 15 percent... When you are short on time, the core strategy is simple: stop trying to cover everything, and pour your energy into the sections that carry the most points...

输出（共 8 张，这里展示第 1 张）：

```markdown
# 短时间备考四六级 · 知识卡片

共 8 张

## 1. 短期备考先算分数账
- **核心知识**：这类考试考的是题型熟悉度，短期应主攻听力和阅读。
- **简明解释**：总分 710、及格 425，不必答对每一题。听力与阅读合计占 70%，写作和翻译各 15%，但后两者题型和话题可预测，提分并不慢。作者提醒：反复考不过的人，多半不是英语差，而是方法错。
- **例子/自测**：原文数据：听力加阅读占 70%，写作、翻译各占 15%。
```

其余 7 张同格式，讲词汇、精听、听力答题卡、阅读顺序、阅读定位、写作翻译准备、时间规划。

### 示例二：文件输入 → 卡片

输入：`./notes/睡眠与食欲.md`，内容节选：

> 睡眠不足会降低瘦素水平、升高胃饥饿素水平，因此人更容易感到饥饿。一项针对 12 名志愿者的实验显示，连续两晚只睡 4 小时后，受试者次日平均多摄入 300 千卡。

输出：

```markdown
# 睡眠与食欲 · 知识卡片

共 N 张

## 1. 缺觉为什么会变饿
- **核心知识**：缺觉改变两种食欲激素，让饥饿感被放大。
- **简明解释**：瘦素负责传递饱腹信号，胃饥饿素负责传递饥饿信号。缺觉让前者下降、后者上升，所以人更容易饿。
- **例子/自测**：原文举例：12 名志愿者连续两晚只睡 4 小时，次日平均多摄入 300 千卡。
```

### 示例三：信息不足时

输入只有一句"给新同事的三条建议：先搞清楚谁决定你的优先级；把问题问成选择题；每周写一次三行总结。"

输出会变成 3 张卡，开头一行说明：

```markdown
# 给新同事的建议 · 知识卡片

原文信息量有限，共 3 张
```

不会为了凑满 5 张而补充原文没有的内容。

## 目录结构

```
make-knowledge-cards/
├── README.md                           # 本文件
└── skills/make-knowledge-cards/
    ├── SKILL.md                        # 技能定义：输入、流程、选点判据、卡片字段、自检
    └── agents/openai.yaml              # 界面元数据（display_name / short_description / default_prompt）
```

## 限制（不支持）

- 网页抓取：给 URL 时会要求你改贴正文。
- PDF、图片、扫描件解析。
- Anki / Quizlet 导出。
- 图形界面。
- 只处理文本输入，不处理音频、视频、图片文件。

## 测试与校验

用 6 类文本实测过：中文科普长文、英文步骤教程、观点评论、数据报告、超短清单、含模糊数字的争议文本。据此补充了四条规则：结论与其直接机制、跨日重复动作必须合并；数据卡先给结论、数字下沉；"原文未说明"独立成行；解释不得引入原文没有的名词与因果。

SKILL.md 通过了 skill-creator 的 `quick_validate.py` 校验（输出 `Skill is valid!`）。
